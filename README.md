# 코드닷 검색 등록용 루트 사이트

[코드닷 사용하기](https://0younge.github.io/Chordot/) · [앱 소스](https://github.com/0younge/Chordot)

네이버 서치어드바이저의 호스트 소유확인과 검색엔진의 루트 robots.txt 요청을 위해 사용하는 GitHub Pages 사용자 사이트입니다. 실제 앱은 기존 `/Chordot/` 주소와 Chordot 저장소에서 유지합니다.

- `index.html`: 네이버 소유확인 태그와 코드닷 안내 링크. 대표 주소는 `/Chordot/`입니다.
- `robots.txt`: 전체 공개 경로 수집을 허용하고 앱 사이트맵 주소를 안내합니다.
- `.nojekyll`: 파일을 변환하지 않고 정적으로 제공합니다.

GitHub Pages는 `main` 브랜치의 루트 폴더를 배포합니다. 네이버 소유확인 유지를 위해 확인 태그를 지우지 마세요. 검색 수집·노출은 검색엔진이 결정하며 즉시 노출을 보장하지 않습니다.
